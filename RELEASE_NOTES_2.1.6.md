# OpenLimiter 2.1.6

Something keeps your bars current. The desktop app starts when you sign in and stays in the tray, so your bars keep refreshing after a restart; Settings turns it off. Opening the app again shows the running window instead of a second copy.

An idle Claude Code window can no longer replace a newer 5 hour reading with an old one. Claude Code reruns the OpenLimiter status line every minute while idle, unless you set a longer interval yourself, so an idle window soon stops showing an old number as current.
