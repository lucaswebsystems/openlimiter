# OpenLimiter 2.0.2

One small tab with the OpenLimiter logo replaces the Rail on the left edge of your screen. Hover it to see your limits and agents in a panel beside it. It works the same on Windows, macOS and Linux X11; on Linux Wayland the tray takes its place.

Home shows only the account signed in now, one card per tool. Anything that cannot be measured is listed on Connections under Needs attention, with one fix each.

The terminal status line leaves out the folder unless you run `openlimiter terminal show dir`, and leaves out any provider that cannot be measured right now.
