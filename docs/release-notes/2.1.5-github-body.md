Fresher Claude bars, and no reading from before a reset on any surface.

## What changed

* Claude weekly bars are read every five minutes while the desktop app runs with Claude usage on, and while Claude Code draws its status line with the command line poll on. Nothing is read while neither runs.
* A reading from before its weekly reset is never shown, on any surface, the paired phone included.
* In the status line, a reading older than its refresh window turns grey, and keeps its tilde when colours are off; otherwise the tilde marks estimates.
* The command line recovers from a rotated Claude login.
* A weekly bar that Anthropic stops reporting disappears after a complete read.

## Platform notes

* The builds are unsigned. On Windows, SmartScreen warns: choose More info, then Run anyway.
* macOS: this dmg carries no signature at all, so macOS can report the app as damaged, and Open Anyway may not be offered. On a Mac, `npx openlimiter` still gives you the terminal bars.
* macOS updates are manual: download the new dmg and replace OpenLimiter in Applications. Windows and Linux update from inside the app.
* Linux: the AppImage needs libfuse2 (`libfuse2t64` on Ubuntu 24.04). On Wayland, the tray takes the place of the edge tab.
* Check any download against the SHA256 digest GitHub shows beside each file below.

## Upgrade notes

* Windows and Linux: the desktop app checks GitHub for updates and asks before installing 2.1.5. You can also download the installer below.
* macOS: download `OpenLimiter-macos-universal.dmg` below and replace the app in Applications.
* Command line: `npm install -g openlimiter@2.1.5`, or run `npx openlimiter@2.1.5`.
* Terminal bars: if the desktop app says the terminal runtime is older than OpenLimiter, run the command it shows, `npx -y openlimiter@2.1.5 terminal install <host>`.
