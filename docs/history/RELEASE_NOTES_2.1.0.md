# OpenLimiter 2.1.0

Claude shows one number per bar on every surface. The Claude bucket allowlist keeps the supported windows together, including Current session, Weekly all models and Weekly Fable.

The terminal has clear captions for 5h, 7d, fable7d, cx7d and ag5h. Money cells such as `or $` keep their amounts. Pro adds the tagged captions preset, and setup upgrades the runtime when needed.

The desktop paints faster on first open. Its buttons work, and Connect repairs a Codex connection that stopped reading. Usage, Connect Tools and Settings now share a responsive window.

The phone app installs to the Home Screen, follows the phone light or dark theme, keeps the last readings offline and includes the Pro tab.

OpenRouter now accepts a management key in Connect Tools, which adds your balance to the status line.
