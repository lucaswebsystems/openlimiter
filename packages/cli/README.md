# `openlimiter`

A local command line meter for AI quota, usage, and reset times.

Most users should install this CLI. Run `openlimiter demo` after installation to see it in action.

Maintainers must run `npm login` before running the root release command.

See the [repository](https://github.com/lucaswebsystems/openlimiter) and [OpenLimiter site](https://openlimiter.com).
