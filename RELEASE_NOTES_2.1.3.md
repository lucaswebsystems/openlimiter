# OpenLimiter 2.1.3

Antigravity shows its bars on Windows. Antigravity CLI runs the status line command through cmd with escaped quotes, so the quoted command the installer wrote was never found. The installer now writes a quote free command, using a short path when a folder name has a space. Run `npx -y openlimiter@2.1.3 terminal install antigravity` once, or click Set up status line in Connect Tools.
