# OpenLimiter 2.1.1

Desktop sign in works again with Google, GitHub and email: the app no longer refuses Supabase's twelve character refresh tokens, and a refused sign in names its error code.

Weekly limits stay visible when an older terminal runtime is installed; the Usage tab shows the command that updates it.

Every command the desktop shows is pinned to the app version, the Antigravity setup panel is laid out cleanly, stuck background refresh processes no longer pile up on Windows, and DeepSeek shows its official mark.
